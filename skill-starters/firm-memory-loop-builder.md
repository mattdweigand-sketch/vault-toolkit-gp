# SKILL: Firm Memory Loop Workspace Builder

## Description
Builds a generic learning-loop workspace for repeated GP judgment that should compound.

## When to Use
When the firm wants to capture outcomes, validate why they happened, and build a store that informs future decisions.

## Process

### Phase 1: Diagnosis

Read `_shared-config/firm-profile.md`, `_shared-config/voice-and-tone.md` at summary depth, and `_shared-config/learnings.md` sections `## General` and `## firm-memory-loop`.

Ask one question at a time:

1. What repeated event or outcome should the firm learn from?
2. Where do the factual records live?
3. What canonical questions should every record answer?
4. What taxonomy makes records comparable?
5. Who validates causal claims before capture?
6. Which future workflow should read the store?

### Phase 2: Assembly

Copy `architectures/firm-memory-loop/` to `workspaces/<name>/`. Populate `_config/questions.md`, `_config/taxonomy.md`, `_config/store-schema.md`, and `_config/before-you-trust-this.md`.

Load and name constraints: 06, 09, 03, 04, 08, 10.

### Phase 3: Orientation

Explain that the store is the deliverable, and that causal claims do not enter the store without human validation.
