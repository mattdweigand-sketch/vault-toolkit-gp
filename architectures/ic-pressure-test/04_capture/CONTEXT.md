# Stage 04: Capture

## Purpose
After the IC decision, capture what the pressure test changed and which questions mattered.

## Inputs
- `03_conditions/output/ic-questions-and-conditions-[deal]-[date].md`.
- Final IC decision and conditions.
- `_store/` current patterns.

## Process
1. Record which pressure-test issues were resolved, conditioned, ignored, or decisive.
2. Capture any recurring IC challenge pattern.
3. Write a short learning for future memos.
4. Update `_store/patterns.md` without overstating one case as policy.

## Output
Write `04_capture/output/captured-pressure-test-[deal]-[date].md` and update `_store/patterns.md`.

## Done Looks Like
Future pressure tests can reuse what this IC discussion taught without manufacturing precedent.
