# Stage 02: Diagnosis

## Purpose
Explain what is causing the signal and whether it is timing, structural, or noise.

## Inputs
- `01_signal/output/signal-[asset]-[period].md`.
- `_config/business-plan-targets.md`.
- `_config/intervention-standards.md`.

## Process
1. Compare the signal to the business plan and intervention standards.
2. Attribute likely cause using available evidence.
3. Distinguish timing variance from structural issue.
4. Rate severity and confidence.
5. Identify what evidence would change the diagnosis.

## Output
Write `02_diagnosis/output/diagnosis-[asset]-[period].md`.

## Done Looks Like
The portfolio lead knows whether this requires action and what uncertainty remains.
