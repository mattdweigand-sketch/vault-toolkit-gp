# Verified Fact Pack

Assembles the facts a downstream narrative or decision stage may use.

Use this when the output needs platform-verified figures, source IDs, audience restrictions, or forbidden claims. Do not use it to compute official figures.

Implements constraints 09, 10, and 08.

Used by `lp-narrative-and-issue-prep`, `ic-pressure-test`, `hold-sell-refi`, and `portfolio-intervention`.
