# Stage 04: Follow-Up

## Purpose
Check whether the action changed the portfolio read.

## Inputs
- `03_action_plan/output/action-plan-[asset]-[period].md`.
- Updated platform-verified signal or owner update.

## Process
1. Record what changed since the action plan.
2. Mark each action complete, open, blocked, or escalated.
3. Update the diagnosis if evidence changed.
4. Capture reusable intervention learning.

## Output
Write `04_follow_up/output/follow-up-[asset]-[period].md`.

## Done Looks Like
The action loop is closed or explicitly escalated.
