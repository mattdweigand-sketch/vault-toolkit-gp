# Source Provenance

Inspects a source set before drafting, analysis, or decision support uses it.

Use this when files arrive from a data room, shared drive, email thread, or unreviewed folder. Do not use it to replace a platform document register that already tracks version, owner, permission, and status.

Implements constraints 10, 09, and 08.

Used by `diligence-evidence-map`, `market-thesis-to-investment-box`, IC intake, and source-grounded deliverables.
