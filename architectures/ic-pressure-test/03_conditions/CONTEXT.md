# Stage 03: Conditions

## Purpose
Turn the challenge pack into IC-ready decision questions, approval conditions, and pre-meeting work items.

## Inputs
- `02_challenge/output/challenge-[deal]-[date].md`.
- `_config/ic-standards.md`.

## Process
1. Convert each approval blocker into a required pre-IC work item.
2. Convert each unresolved but acceptable risk into a possible approval condition.
3. Write the committee questions in direct language.
4. Name the owner and needed evidence for each item.
5. Separate "must resolve before IC" from "condition if approved."

## Output
Write `03_conditions/output/ic-questions-and-conditions-[deal]-[date].md`.

## Done Looks Like
The deal team has a short list of questions and conditions that can be used in the IC meeting without rewriting.
