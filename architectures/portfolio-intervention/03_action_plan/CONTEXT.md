# Stage 03: Action Plan

## Purpose
Turn the diagnosis into owned next steps.

## Inputs
- `02_diagnosis/output/diagnosis-[asset]-[period].md`.
- `_config/action-plan-format.md`.

## Process
1. Decide whether the response is monitor, investigate, intervene, escalate, or prepare IC decision.
2. Write the action, owner, deadline, and required evidence.
3. Name the expected change or trigger for escalation.
4. Flag any hold / sell / refinance signal without making the decision.

## Output
Write `03_action_plan/output/action-plan-[asset]-[period].md`.

## Done Looks Like
The plan names who does what by when and what evidence determines whether the issue is resolved.
