# LP Narrative And Issue Prep Workspace

## What This Is
A workspace for preparing LP-facing explanations around platform-verified facts. It helps draft narrative, prepare likely questions, and set response posture for sensitive issues.

Juniper Square or the investor platform owns LP records, figures, reporting, DDQ, portal delivery, entitlements, and audit. This workspace owns the language and judgment around those facts.

- `modules/grounded-draft/CONTRACT.md`
