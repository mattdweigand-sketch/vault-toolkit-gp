# Assumption Taxonomy — Ridgeline Capital Partners

The controlled vocabulary for tagging each record so the store aggregates into a calibration table.
Stable since v1.0 (2023-01).

## Asset Type
multifamily · industrial *(Ridgeline underwrites only these two)*

## Deal-Size Band
< $25M · $25M–$75M · $75M–$250M · > $250M

## Market / Submarket
Phoenix (Tempe, Mesa) · Tucson · Las Vegas · Inland Empire · Reno *(our active markets)*

## Strategy
core-plus · value-add *(Ridgeline runs value-add primarily, occasional core-plus)*

## Hold-Period Band
< 2 yrs · 2–4 yrs · 4–7 yrs · > 7 yrs

## Vintage Year
The year the deal was approved at IC (2016 onward).

## Assumption Category *(controlled — every material miss tags to one)*
Going-in cap rate · Rent / revenue growth · Opex growth · Lease-up / absorption pace ·
Exit cap rate · Hold period · Leverage / cost of debt · Capex / renovation budget · Terminal value

## Outcome vs. Underwriting
Outperformed · In-line · Underperformed · Interim-checkpoint *(flagged sub-case)*

## Decisive Driver
The single assumption category that drove the variance. Tag the primary; note a secondary if needed.

## Cause Class
forecasting error · execution · exogenous

## Skill / Luck Attribution
skill-dominant · luck-dominant · mixed *(the headline read on the realized return; candid internal
intelligence)*
