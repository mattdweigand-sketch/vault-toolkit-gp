## Platform boundary (GP rule)
This workspace prepares language and judgment. It does not own figures. NAV, capital
account balances, the waterfall, IRR, and any audited number come from the
fund-administration platform or the financial model — cited, never invented, never
blended across versions of a model. See Constraint 09.
