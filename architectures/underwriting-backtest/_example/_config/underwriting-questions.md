# Canonical Underwriting Questions — Ridgeline Capital Partners

The fixed set every Ridgeline backtest answers, in this order, every time. This is what makes the
records comparable. Stable since v1.0 (2023-01); any change is versioned and dated.

## The Questions
1. Which assumptions were material to the realized return — the few that actually moved the IRR?
2. For each material assumption: underwritten value vs. actual, and the variance (magnitude and
   direction)?
3. On the headline return (IRR and equity multiple): underwritten vs. realized, and the gap?
4. For each material miss — forecasting error (we assumed wrong), execution (we delivered off-plan),
   or exogenous (the market moved)?
5. Skill vs. luck: of the IRR variance, how much is Ridgeline's edge (thesis, execution, forecast)
   vs. market movement we did not create — cap-rate compression, the rate environment, a sector
   run? Keep the two distinct and say which we believe.
6. Is each material miss systematic (consistent with what the store already shows) or one-off?
7. Did we underwrite with full information, or blind on a key input?
8. If outperformed: what was the decisive driver, and is it repeatable?
9. If underperformed: what would we have needed to see at underwriting to get it right — and would
   we have still done the deal?
10. What calibration adjustment does this imply for future underwriting in this segment?

## Answering Rules
- Answer every question, in order. Use "unknown" where the record does not support an answer —
  never fabricate to fill the slot.
- Keep answers tight and factual; the calibration adjustment has its own section in the attribution.
- Distinguish Ridgeline's skill from market luck explicitly; never collapse them.
- Mark systematic vs. one-off on every material miss, so a one-deal anomaly does not get hard-coded
  into our standard assumptions.
