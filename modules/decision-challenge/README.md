# Decision Challenge

Pressure-tests a decision package before a human gate.

Use this when the output should be questions, blockers, approval conditions, or decision-impact risks. Do not use it to make the decision.

Implements constraints 02, 08, 09, and 10.

Used by `ic-pressure-test`, `hold-sell-refi`, `market-thesis-to-investment-box`, and `portfolio-intervention`.
